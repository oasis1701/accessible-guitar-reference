Neural DSP Plugins Accessibility

Neural DSP Plugins Accessibility is an add-on for the NVDA screen reader. It makes five Neural DSP guitar plug-ins usable with a screen reader, the Archetype Petrucci X, the Archetype Nolly X, the Fortin Nameless Suite X, the Soldano SLO-100 X, and the Archetype Cory Wong X. It names their controls, says knob values and switch positions, and adds single keys for things a mouse user does at a glance, such as switching sections, stepping through presets, running the tuner, and checking levels. It is a separate project by the author of this site.

Neural DSP has videos of John Petrucci and Nolly with their own plug-ins, and tutorials on dialing in a tone with each one. Watch Neural DSP's videos about both plug-ins.

    This link always downloads the newest release, which NVDA installs when you open it.

  • Read the full keyboard guide

    The guide lists every key, names the sections of all three plug-ins in the order your guitar passes through them, and explains moving in and out of a plug-in.

  • Read the release notes on GitHub

    The release notes say what changed in the newest release.

After you install the add-on, the keyboard guide also opens from its Help action in NVDA's Add-on Store.

Requirements

You need NVDA and at least one of the three plug-ins. For the best results, install the VST3 versions of the plug-ins and use them inside REAPER, which is where the add-on is tested. To use REAPER with a screen reader, you also need the free OSARA extension. The standalone applications are still being worked on and tested. The add-on is in its early releases, tested with NVDA 2026.3.1.

Install the add-on

  1. Download the add-on with the download link on this page.
  2. Open the file, and confirm the installation when NVDA asks.
  3. Restart NVDA when it asks.

A newer release installs the same way and replaces the one you have.

In REAPER, open the plug-in's FX window and press NVDA+Shift+A to step into the plug-in, or NVDA+Shift+G with NVDA's laptop keyboard layout. Press the same key again to step back out.
